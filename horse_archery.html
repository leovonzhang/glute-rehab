1 装备

弓、箭、握弓与勾弦

弓：短弓 / 反曲角弓

  • 骑射一般用较短的反曲弓或角弓（传统亚洲式、韩弓、土耳其/匈牙利式等），弓长常见约120-140厘米，马上不碰马颈和马鞍。
  • 初学磅数宁轻勿重：一般20-30磅，按体力选。标准是能稳定拉满、在靠位停5秒不发抖，并连续射30支以上动作不变形。
  • 磅数通常按28英寸拉距标注；你的实际拉距不同，实际磅数也会不同。买弓前先量拉距：双臂侧平举，两手中指尖距离÷2.5，约等于拉距。
  • 弓要和拉距匹配：拉距超过弓的设计拉距会明显变重，也容易损坏弓。

箭

  • 箭长 = 拉距 + 余量（一般多出约2-5厘米），拉满时箭头仍在弓手前方，不会拉过头落到手上。
  • 脊度（箭的软硬）要和弓的实际磅数、箭长匹配，按箭材厂家的脊度表选；同一组箭的长度、重量、脊度要一致。
  • 羽毛：拇指射法一般不用箭台，箭直接搭在弓手上，要用天然羽毛（软羽），塑料羽片会刮手、乱飞。
  • 初学用竹箭、木箭或碳箭都可以，带几支备用；箭头用练习用的靶头。

握弓

  • 虎口推弓：弓把压在虎口下方、掌根偏拇指一侧，用骨骼结构把弓推向靶。
  • 手腕不折：手腕与前臂保持一条线，不往里扣也不往外翻。
  • 不死握：手指松松包住弓把，撒放时弓自然前倾，不要攥紧扭弓。

扳指与拇指射法

  • 拇指射法（亚洲/蒙古式）：戴扳指的拇指从箭的下方勾住弦，食指压在拇指上锁住，其余手指收拢。
  • 右手射手的箭放在弓的右侧（地中海式在左侧），这和撒放时弦从拇指上滑出的方向有关。
  • 扳指（皮扳指或硬扳指）要合手，不松不紧；初学可以先用皮扳指，硬扳指需要适应。
  • 撒放靠放松拇指：食指先松开，弦把拇指推开，不要主动“弹”拇指。

地中海式（可选替代）

  • 三指勾弦：食指在箭上方，中指、无名指在箭下方（也有三指都在箭下方的做法）。
  • 右手射手箭放在弓左侧；需要护指皮或射箭手套保护手指。
  • 很多人从地中海式入门、比较容易上手；骑射里两种都有人用，选一种练到稳定，不要来回换。

护具

  • 护臂：戴在弓手前臂内侧，防止弦打到手臂。
  • 弓手手套：箭直接从手上过，手套可以防箭羽、箭杆划伤虎口和手背。
  • 马上练习另需马术头盔、合适的鞋（有鞋跟、不易卡镫），可选护背。

1.1

扳指勾弦与地中海式对比

拉弦手特写
第1步拇指射法：戴扳指的拇指从箭的下方勾住弦
  1. 拇指射法：戴扳指的拇指从箭的下方勾住弦
  2. 食指压在拇指上锁住，其余手指自然收拢
  3. 开弓：手腕和拇指放松，靠背部发力往后拉
  4. 撒放：食指松开、拇指放开，弦自己把拇指推开
  5. 对比地中海式：食指在箭上方，中指、无名指在箭下方勾弦（戴护指皮）
  6. 地中海式开弓：三指勾弦，手背放松
  7. 地中海式撒放：三指同时放松

要点

  • 拇指在箭下方勾弦，扳指受力，食指压住拇指。
  • 开弓时手腕、拇指放松，力量来自背部。
  • 撒放时放松，不主动弹手指。
  • 地中海式：食指在箭上，中指、无名指在箭下，三指同时放松。

常见错误

  • 拇指勾得太深或太浅，撒放时卡弦。
  • 撒放时手往外甩。
  • 不戴扳指/护指皮直接拉。

2 安全基础

先安全，再练技术

射箭场地与人员

  • 只在有安全区和挡箭设施的场地射，靶后和箭道两侧不能有人或通道。
  • 统一口令：所有人回到射线后才开射；有人去捡箭时全员停射，弓放下、箭不上弦。
  • 搭好箭后箭头只朝靶或朝地面；永远不对人、动物或天空射箭。

空放的危害

  • 空放：不搭箭就拉弓撒放。弓的能量没有箭带走，全部回到弓臂和弦上，可能使弓臂断裂、弦崩断，伤到自己和旁人。
  • 不空拉放：不搭箭时不拉满撒放。练开弓用弹力带，或搭好箭后慢慢还原。

每次射前检查

  • 弓：弓臂有无裂纹、分层、扭曲；弦有无发毛、断股，弦上的护线和箭扣点是否完好。
  • 箭：箭杆有无裂纹（轻轻弯一下听有没有破裂声）、箭尾有无破损、箭头是否牢固、羽毛是否完整。

马匹安全

  • 马上练习必须戴马术头盔，使用合适、检查过的马具（马鞍、马镫、可打结的缰绳）。
  • 由教练或助手牵马，或在圆场/封闭场地里练；从慢步开始，过关后再加速。
  • 马要对弓、箭飞过、弓弦声和骑手动作脱敏，这需要专业人员训练。不要在没训练过的马上射箭。
  • 遵守马场规则，听从教练指令。

个人体能与热身

  • 射箭前先做肩部热身（见开肩页的持棍绕肩），再做几次轻拉。
  • 骑射对核心、髋和背部的稳定要求高；疲劳时动作容易变形，要及时停。
  • 腰背不适时停止练习：出现腰痛、腿麻或放射痛，先停练，就医评估后再继续。

3 地面基础

先热身：射箭前先做开肩（持棍绕肩等），开肩是拉弓前的热身；再用轻弓或弹力带拉几次。
3.1

站姿

地面基础 · 正面看（靶在射手左侧）
第1步侧对靶站立（靶在身体左侧），双脚与肩同宽自然呼吸
  1. 侧对靶站立（靶在身体左侧），双脚与肩同宽
  2. 膝微屈，重心落在两脚中间
  3. 呼气收肋骨、下腹微收，站稳
  4. 头转向靶，眼睛看靶心，肩不转

要点

  • 侧对靶，双脚与肩同宽，脚尖大致平行或略外开。
  • 膝微屈，重心在两脚中间，不前后晃。
  • 呼气收肋骨、下腹微收，背不塌也不拱。
  • 只转头看靶，肩和髋保持侧对靶。

常见错误

  • 身体正对靶或扭着站。
  • 膝锁死、挺肚子塌腰。
  • 肋骨顶出，上身后仰。
3.2

搭箭

握弓与搭箭 · 从射手身后看
第1步左手虎口推弓，手指放松包住弓把，手腕不折
  1. 左手虎口推弓，手指放松包住弓把，手腕不折
  2. 拇指射法：箭放在弓的右侧（右手射手），搭在弓手的拇指/虎口上
  3. 对比：地中海式射法，箭放在弓的左侧
  4. 箭尾的箭扣卡到弦上的箭扣点，再勾弦

要点

  • 弓手先握好弓：虎口推弓、手指放松、手腕不折。
  • 拇指射法（右手射手）：箭放在弓的右侧，搭在弓手的拇指/虎口上。
  • 箭尾的箭扣卡到弦上的箭扣点，每次同一位置。
  • 搭箭时箭头始终朝靶或朝地面。

常见错误

  • 拇指射法却把箭放在弓左侧（左右搞反）。
  • 箭扣没卡牢就开弓，箭会掉。
  • 搭箭时箭头指向旁人。
3.3

推弓开弓

地面基础 · 正面看
第1步举弓：弓手虎口推弓、手腕不折，拉弦手拇指勾弦吸气
  1. 举弓：弓手虎口推弓、手腕不折，拉弦手拇指勾弦
  2. 推和拉同时进行：弓手推向靶，拉弦手沿直线往后
  3. 背部发力、肩胛后收、沉肩，拉到靠位
  4. 错误：耸肩、只用手臂硬拉
  5. 纠正：沉肩，拉弦手的手肘往后走，背发力
  6. 练开弓时不撒放：用背部控制慢慢还原
练习量开弓练习不撒放：8-10次×3组，每次靠位停3秒后慢慢还原。

要点

  • 推拉同时：弓手推向靶，拉弦手沿直线往后拉到靠位。
  • 用背部发力：肩胛往后收、拉弦手的手肘往后走。
  • 沉肩，脖子放松，不耸肩。
  • 开弓时慢慢呼气，靠位时稳定。

常见错误

  • 耸肩、只用手臂拉。
  • 弓手手腕折、死握弓把。
  • 拉弦手往外绕大圈，靠位不一致。
3.4

靠位

把弦拉到脸上的固定点
第1步开弓，把弦拉向脸旁呼气
  1. 开弓，把弦拉向脸旁
  2. 靠位：拉弦手贴在嘴角、下巴或脸颊的固定位置
  3. 选定一个靠位，每一箭都靠在同一点
  4. 靠位后停1-2秒，稳定瞄准
  5. 练靠位时不撒放：慢慢还原

要点

  • 靠位点可以选嘴角、下巴或脸颊，选一个后固定下来。
  • 每一箭都靠在同一点，射出去的箭才会稳定。
  • 拇指射法常见靠在嘴角或脸颊附近，拉距会比地中海式略长。
  • 靠位后停1-2秒再撒放。

常见错误

  • 每箭靠位不同。
  • 为了碰到脸而歪头、探脖子。
  • 一到脸边就撒放，没有稳定。
3.5

撒放

放松拇指 + 跟随动作
第1步靠位稳定，背部继续轻轻发力屏住
  1. 靠位稳定，背部继续轻轻发力
  2. 放松拇指：食指先松开，弦把拇指推开，箭飞出
  3. 跟随动作：拉弦手顺势往后，弓手继续推向靶
  4. 保持姿势约1秒，再放下
  5. 重新搭箭、勾弦，准备下一箭

要点

  • 撒放是“放松”，不是“松手甩”：食指先松开，弦把拇指推开。
  • 背部继续发力，拉弦手顺势往后（跟随动作）。
  • 弓手继续推向靶，不放下、不甩弓。
  • 保持姿势约1秒，看着箭中靶。

常见错误

  • 撒放时拉弦手往前送（泄力）。
  • 弓手撒放瞬间往下掉或往旁边甩。
  • 撒放后马上放下弓，没有跟随。
3.6

呼吸节奏

每一箭的呼吸配合
第1步举弓前：吸气，肋骨往两侧打开吸气
  1. 举弓前：吸气，肋骨往两侧打开
  2. 开弓过程中：慢慢呼气（呼出一部分）
  3. 靠位瞄准：短暂停住呼吸，保持稳定
  4. 撒放
  5. 撒放后：把气完全呼出、放松，再开始下一箭
  6. 放下弓，自然呼吸1-2次

要点

  • 举弓前吸气。
  • 开弓时慢慢呼气，呼出一部分。
  • 靠位瞄准时短暂停住呼吸、保持稳定（几秒即可）。
  • 撒放后完全呼出、放松，再开始下一箭。

常见错误

  • 全程憋气，脸红脖子粗。
  • 靠位停太久，憋到发抖才撒放。
3.7

空拉不撒放练习

练力量和靠位，不伤弓
第1步用弹力带，或搭好箭的轻弓来练吸气
  1. 用弹力带，或搭好箭的轻弓来练
  2. 开弓到靠位
  3. 靠位保持3-5秒，背部持续发力
  4. 用背部控制，慢慢还原，不撒放
  5. 每组8-10次，组间休息1分钟
练习量3组×8-10次，每次靠位停3-5秒。

要点

  • 用弹力带，或搭好箭的轻弓练。
  • 拉到靠位停3-5秒，背部持续发力。
  • 用背部控制慢慢还原，不撒放。
  • 每组8-10次×3组，组间休息约1分钟。

常见错误

  • 不搭箭拉满后撒放（空放），会伤弓伤人。
  • 还原时突然松掉，弦弹回手。
  • 为了多做几次而耸肩、动作变形。
3.8

快速取箭搭箭

为骑射的速度打基础
第1步箭插在右腰侧的箭袋里，弓手举弓准备
  1. 箭插在右腰侧的箭袋里，弓手举弓准备
  2. 拉弦手伸到箭袋，捏住箭尾取箭
  3. 把箭抽出，箭杆贴着弓滑到弓的右侧
  4. 箭尾扣弦，拇指勾弦
  5. 立即开弓、靠位
  6. 撒放；熟练后从取箭到撒放约3-5秒
练习量每次练20次左右，熟练后计时。

要点

  • 箭袋位置固定（右腰侧），或把几支箭夹在弓手里（见5.4）。
  • 取箭时捏箭尾，箭杆贴着弓滑上去，箭头始终朝前方。
  • 不低头看手，靠手感找到箭扣点。
  • 先慢后快：动作正确后再计时，目标从取箭到撒放约3-5秒。

常见错误

  • 低头找箭、找弦。
  • 取箭时箭头扫过身边的人。
  • 求快导致靠位、撒放变形。

4 马上基础

注意：以下内容必须在专业马场、由教练安排合适的马和场地，在教练指导下进行；从慢步开始，每一步过关后再加速。
4.1

慢步骑乘姿势

马上基础 · 侧面看
第1步坐正：耳、肩、髋、脚跟大致在一条线上
  1. 坐正：耳、肩、髋、脚跟大致在一条线上
  2. 脚跟下沉，小腿轻贴马腹，双腿夹住保持稳定、控制方向
  3. 缰绳打结挂在马颈上，双手离缰（由教练牵马/控马）
  4. 髋跟着马的步伐前后摆动，上身保持稳定
  5. 慢步是四拍：1-2-3-4，先在慢步里找到节奏

要点

  • 坐正，耳-肩-髋-脚跟大致一条线，重心坐在坐骨上。
  • 脚跟下沉，小腿轻贴马腹，用双腿夹住保持稳定、控制方向。
  • 缰绳打结挂在马颈上，双手离缰；初期由教练牵马或在圆场里练。
  • 髋跟着马的步伐前后摆动，上身保持稳定。

常见错误

  • 抓鞍、抓鬃毛来保持平衡。
  • 身体僵硬，上身跟着马晃。
  • 脚尖往下，脚跟抬起。
4.2

慢步射箭

慢步中完成取箭、开弓、撒放
第1步慢步中举弓，搭箭勾弦
  1. 慢步中举弓，搭箭勾弦
  2. 上身转向射击方向（图中示意为左前方），推弓开弓
  3. 靠位稳定后撒放
  4. 跟随动作，髋继续随马摆动，上身稳定
  5. 重新搭箭；先在慢步里多练几趟再加速

要点

  • 先在慢步中练持弓开弓不撒放，再搭箭射。
  • 右手射手主要向马的左侧射（左前方、正左方）。
  • 转的是上身，髋仍然随马运动。
  • 撒放后跟随，眼睛看靶，马继续直行。

常见错误

  • 射箭时用腿乱踢马或拉缰。
  • 为了瞄准而身体后仰。
  • 撒放后马上放下弓，没有跟随。
4.3

快步：起坐、两点式与快步射

快步（trot）是两拍步法
第1步快步是两拍：马每走一步，你会被往上弹一次
  1. 快步是两拍：马每走一步，你会被往上弹一次
  2. 轻快步（起坐）：一拍起身、一拍坐下，跟上马的节奏
  3. 射箭时改两点式：站在马镫上，膝和脚踝吸收震动
  4. 两点式中开弓：上身稳定，不跟着马弹
  5. 撒放（快步射）
  6. 放下弓，回到起坐，准备下一趟

要点

  • 轻快步（起坐）：一拍起身、一拍坐下，用大腿和膝发力，跟上马的节奏。
  • 射箭时改为两点式：站在马镫上，膝和脚踝吸收震动，上身不随马弹。
  • 两点式中开弓、撒放；先练开弓不撒放。
  • 脚跟下沉、小腿贴住马，是两点式稳定的关键。

常见错误

  • 坐着硬颠，上身被马弹起。
  • 两点式时站得太直、膝锁死。
  • 射箭时双腿离开马身。

5 进阶

5.1

跑步节奏：腾空期撒放

跑步/袭步（canter/gallop）
第1步跑步（袭步）是三拍加腾空：1-2-3-腾空
  1. 跑步（袭步）是三拍加腾空：1-2-3-腾空
  2. 髋随马前后“滚动”，上身稳定
  3. 跟着节奏：着地的三拍里开弓，腾空期撒放
  4. 每个步幅一射，练稳定的节奏

要点

  • 跑步是三拍加一个腾空期：1-2-3-腾空。
  • 着地的三拍里完成开弓，腾空期马最平稳，在这时撒放。
  • 髋随马前后“滚动”，上身和头保持稳定。
  • 先持弓开弓不撒放练节奏，稳定后再搭箭。

常见错误

  • 不管节奏随时撒放，箭忽高忽低。
  • 上身跟马前后点头。
  • 为了跟节奏而憋气。
5.2

射击方位：前射、侧射、后射、低位射

俯视图 · 右手射手向马的左侧射
第1步前射：向左前方约45°开弓
  1. 前射：向左前方约45°开弓
  2. 前射撒放
  3. 侧射：上身转向正左方
  4. 侧射撒放
  5. 后射（回身射/帕提亚射）：上身向左后方转，越过左肩向后射
  6. 后射撒放
  7. 低位射：上身侧倾，向马左下方近处的地靶射
  8. 低位射撒放

要点

  • 前射：向左前方约45°，提前射向迎面的靶。
  • 侧射：上身转向正左方，最容易先掌握。
  • 后射（回身射/帕提亚射）：上身向左后方转，越过左肩向后射，转体靠胸椎和髋，腰不硬拧。
  • 低位射：上身侧倾，向马左下方近处的地靶射，双腿要夹稳。

常见错误

  • 只转手臂不转上身，开弓变形。
  • 后射时用腰硬拧。
  • 低位射时重心滑出马鞍。
5.3

靶道练习

多靶连续射 · 俯视示意
第1步从起点加速，进入稳定的跑步
  1. 从起点加速，进入稳定的跑步
  2. 前射：提前瞄准前方的第1个靶
  3. 侧射：经过第2个靶时向左侧射
  4. 后射：回身射已经过去的第3个靶
  5. 冲过终点后减速；看成绩、捡箭（全员停射时）

要点

  • 靶道一般是直线，靶在骑手左侧；按顺序前射、侧射、后射。
  • 先在慢步、快步里走靶道，熟练后再用跑步。
  • 每趟前想好每个靶用哪个方位射。
  • 练习时有专人看场，捡箭时全员停射。

常见错误

  • 速度超过自己的能力。
  • 射完一靶后急着取箭而失去平衡。

韩式 / 匈牙利式赛道简介

  • 韩式骑射：常见项目有单射（一个侧方靶）、速射（同一侧连续射多个靶或多箭）、连射（前、侧、后不同方向的靶），还有追射拖在马后的“毛球”（模毬）等。
  • 匈牙利式（Kassai体系）：一条约90米的直线赛道，靶在赛道中段一侧，要在时限内尽量多射，前射、侧射、后射都可以用。
  • 具体距离、时限和计分以各赛事章程为准；初学先在教练安排的短靶道上练，速度从慢步开始。
5.4

快速连射

弓手夹箭，连续射多箭
第1步弓手握弓，同时夹住几支箭（箭头朝前）
  1. 弓手握弓，同时夹住几支箭（箭头朝前）
  2. 拉弦手从弓手里抽出一支，往后滑到箭尾扣弦
  3. 开弓、靠位
  4. 撒放
  5. 马上取下一支
  6. 扣弦
  7. 开弓、靠位
  8. 撒放：节奏连贯，每一箭动作不变形

要点

  • 弓手握弓的同时夹住几支箭，箭头朝前。
  • 拉弦手从弓手里抽箭、滑到箭尾扣弦，一个连贯动作。
  • 先慢后快：每一箭的开弓、靠位、撒放都不能省。
  • 地面练熟（连续3箭约10秒内）后再上马。

常见错误

  • 求快导致没有靠位就撒放。
  • 抽箭时箭头乱晃。

6 渐进周训练计划

每周安排（参考）

以下是一个参考进度：每阶段约4周，达到过关标准再进入下一阶段，不要按日期硬推进。马上部分全部在专业马场、由教练安排马匹和课程；地面部分可以在射箭馆按传统射箭的方式练。

第1-4周：地面基础（每周3次，技术+力量）

训练日内容时长组数/量过关标准
第1次（如周四）站姿、握弓、勾弦、推弓开弓、靠位；空拉不撒放（弹力带或搭箭的轻弓）+ 近距离射45-60分钟空拉3组×8-10次；射5-8米，第1周约30支，逐周加到60支开弓不耸肩，靠位每次一样
第2次（如周六，可替换爬山）射箭馆完整练习：一套完整动作 + 呼吸节奏60-90分钟10组×6支（约60支），第4周可到80支8-10米，每组6支中至少4支上靶
第3次（如周一或周五练后）辅助力量 + 快速取箭搭箭20-30分钟弹力带面拉3×15、弹力带外旋2×15、侧平板/Pallof推各2组；取箭搭箭20次取箭到撒放≤6秒，动作不乱
阶段过关可以进入慢步——连续射60支动作不变形；10米上靶率约80%；靠位停5秒不发抖；取箭到撒放约5秒

第5-8周：慢步（马场2次 + 地面1次）

训练日内容时长组数/量过关标准
马场课1慢步骑乘：教练牵马或在圆场里，缰绳打结挂在马颈，练双手离缰的平衡30-45分钟离缰慢步5分钟×3-4次离缰慢步时不抓鞍、上身稳定
马场课2慢步射：先空手模拟开弓，再持弓开弓不撒放，最后搭箭射侧方的靶30-45分钟10-15趟，每趟1-2箭慢步中搭箭开弓不用低头看手
地面1次技术复习 + 快速取箭搭箭 + 辅助力量45分钟射40-60支；取箭搭箭20次取箭到撒放≤5秒
阶段过关可以进入快步——连续两次课，慢步侧射（5-8米）上靶约一半以上

第9-12周：快步（马场2次 + 地面1次）

训练日内容时长组数/量过关标准
马场课1轻快步（起坐）节奏 + 两点式；先不拿弓，再持弓30-45分钟两点式30秒×6-8次两点式30秒上身不晃，起坐跟得上节奏
马场课2快步射，以侧射为主30-45分钟10-15趟，每趟1箭快步中稳定开弓，侧射上靶约一半
地面1次连射：弓手夹箭、连续3箭；呼吸节奏45分钟3箭×10组连续3箭≤10秒，每箭动作不变形
阶段过关可以进入跑步——教练确认快步骑乘稳定；能在快步中完成取箭、搭箭、撒放

第13周以后：跑步 + 多方位

训练日内容时长组数/量过关标准
马场课1跑步（袭步）骑乘稳定，练“着地开弓、腾空撒放”的节奏；先持弓开弓不撒放，再搭箭30-45分钟8-12趟跑步中双手离缰稳定，撒放时机跟上节奏
马场课2靶道：前射→侧射→后射，熟练后加低位射30-45分钟8-12趟，每趟1-3箭单趟前、侧、后各1箭都上靶
地面1次后射、低位射的地面模拟（转体、侧倾）+ 核心与髋稳定训练45分钟每个方位20箭；核心训练见各阶段页面转体后背部仍能发力，腰不代偿
继续进阶在俱乐部按韩式/匈牙利式赛道练习，逐步提高速度和连射数量——由教练评估

结合现有训练安排

  • 骑射对核心和髋的稳定要求高：继续做第一阶段的死虫、鸟狗、臀桥，以及第二阶段的平板支撑、侧平板、Pallof推、髋铰链。
  • 和一周安排的配合：地面技术放在周四（休息+激活日，30-45分钟，轻弓/弹力带）；周六可用射箭馆或马场替换爬山（同为中碳日）；第3次短练放在周一上肢日热身后（先做开肩）或周五步行后；周日保持全休。
  • 同一天不要把大重量下肢训练和骑马叠在一起；骑马后做练后放松。
  • 传统射箭（立射）可以作为地面练习的主要内容：本页的站姿、握弓、开弓、靠位、撒放同样适用。
  • 腰背不适时停：骑乘中或骑乘后出现腰痛、腿麻或放射痛，停止骑马，先就医评估。

安全提示

  • 马上练习须在专业马场和教练指导下进行，马匹必须经过弓箭脱敏训练。
  • 永远只朝靶射；不空放（不搭箭不撒放）；捡箭时全员停射。
  • 戴马术头盔，检查马具、弓、弦和箭。
  • 肩前侧尖锐疼痛或卡住就停；腰背不适、腿麻或放射痛就停，先就医评估。
  • 出现腿麻、放射痛或疼痛加重，先停练并及时就医。
  • 建议找运动康复师当面评估，再根据情况调整动作和强度。
  • 本页为一般性训练示意，不能代替专业医疗建议。
